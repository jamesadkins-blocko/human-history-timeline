# Rendered timeline outputs

Generated outputs belong here. Do not hand-place historical items.

Initial authoritative renderer:
`python scripts/render_timeline_svg.py`

The first build renders the high-density 1500 BCE–500 CE window across synchronized regional lanes from canonical Entities and Date Claims. It intentionally omits claims without normalized numeric coordinates rather than inventing dates.

SVG tooltips expose Entity ID, Date Claim ID, display date, and classification for provenance tracing.
